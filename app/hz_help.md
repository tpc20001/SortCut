# HotZone FM 使用說明

這套軟體結合了四種工具的用法：Windows 檔案總管、Everything 的搜尋、TreeSize 的空間分析，以及 Copy Handler／FastCopy 的搬檔佇列和資料夾同步。最核心的功能是**熱處理**：把常用資料夾裡的檔案，慢慢搬到硬碟碟片的**外圈**，也就是硬碟最快的區域。

另外還有：**圖片分類**（顏色、相似、近似重複、人臉數、時間軸、不用 AI 的文字找圖）、**生圖比較**（ComfyUI／SD 的參數表格）、**影片工具**（長度、無損轉 MP4），以及最重要的**保管區**：任何會讓檔案消失的動作，都會先把原檔保管起來（預設 30 天，可以在設定改）。

軟體架構和你的 TikLive Monitor 一樣，由三部分組成：啟動器 `HotZoneFM.exe`、可以熱更新的 `app\` 資料夾，以及 `v版本_Update.zip` 格式的更新包。另外內建網頁介面，可以從區網或 Tailscale 遠端連回來操作。

---

## 1. 第一次安裝

1. 把整個資料夾解壓縮到一般位置，例如 `D:\HotZoneFM`。
   * **不要**放在 `C:\Program Files`，因為程式需要在自己的資料夾裡寫入設定和更新檔。
2. 製作 exe（只需要做一次）：
   1. 先安裝 **Python 3.12（64 位元）**，網址：<https://www.python.org/downloads/>。安裝時記得勾選「Add python.exe to PATH」。如果你做 TikLive 啟動器時已經裝過，這步可以跳過。
   2. 雙擊 **`build_exe.bat`**。它會自動安裝 PySide6 和 PyInstaller，然後產生 `HotZoneFM.exe` 和 `_internal\` 資料夾。第一次大約需要 5～10 分鐘。
   * 如果暫時不想做 exe，也可以雙擊 `run_from_source.bat`，直接用 Python 執行。
   * 之後如果要用新的完整版**重新製作 exe**，請先在右下角圖示按右鍵 →「結束全部」，不然舊的 exe 被占用會無法覆蓋（build_exe.bat 也會提醒你）。
3. 雙擊 **`HotZoneFM.exe`**。
   * 第一次會跳出「使用者帳戶控制」視窗，請按 **是**。這是給**背景引擎**用的：搬移磁區（熱處理）和讀取 MFT（快速建立索引）都需要系統管理員權限。
   * 主視窗本身**不會**以系統管理員身分執行。這是刻意的設計：Windows 不允許從檔案總管把檔案拖進以系統管理員身分執行的視窗。所以請不要對 exe 按右鍵選「以系統管理員身分執行」。
4. 建議到 **設定 → 背景引擎** 勾選「開機自動啟動」。之後 Windows 登入時，背景引擎會自動以系統管理員身分啟動，也不會再跳出確認視窗。

> 如果更新後的新版本無法啟動，啟動器會自動退回上一個能正常啟動的版本，並把原因寫在 `LOG\startup_log.txt`。

> 關閉主視窗時，程式會縮到右下角的系統匣，**背景引擎會繼續執行**，包括搬檔、熱區搬移和遠端連線。如果要完全結束，請在系統匣圖示上按右鍵 →「結束全部」。

> 第一次打開時會出現「👋 開始使用導覽」，帶你做完自我檢查、指定熱處理資料夾、圖片資料夾、開機自動啟動和遠端設定。之後可以在「設定 → 背景引擎 → 開始使用導覽」再打開。

## 總覽

左邊選單最上面的「📋 總覽」把熱處理進度（含最近幾天的曲線）、傳輸佇列、磁碟空間、保管區、圖片分析、索引、提醒和「最近的動作」放在同一頁，每 3 秒更新，最適合用手機遠端看一眼；點任何一張卡片就會進到那個功能。熱處理頁的「📅 進度紀錄」可以看每天搬了多少。

## 2. 熱處理（最主要的功能）

**原理**：硬碟碟片外圈的磁區每轉一圈經過的資料比較多，所以外圈（也就是磁碟區的最前面）比內圈快 1.5～2 倍。

**使用方式**

0. **第一次使用前，先按「熱處理」頁面上的「🩺 自我檢查」→「完整檢查」。** 它會確認權限、NTFS 功能，並在那顆硬碟的隱藏保管區用一個 8 MB 測試檔實際搬一次、比對內容一模一樣，不會動到你的檔案。全部打勾再開始用；有 ✗ 的話按「複製報告」傳給我。
1. 在「檔案總管」對資料夾按右鍵 → **🔥 標記為熱處理優先**。你也可以先選取資料夾，再按工具列上的「🔥 標記熱處理」。
2. 把檔案移進這個資料夾：
   * **同一顆硬碟、同一個磁碟區**（例如 K:\ 移到 K:\熱）：只是改名，**瞬間完成，檔案馬上可以使用**。
   * **從其他磁碟複製進來**：工作會排進佇列，而且自動**插隊優先處理**。
3. 背景引擎接著會用 Windows 磁碟重組使用的同一個 API（`FSCTL_MOVE_FILE`），把這些檔案的磁區慢慢搬到外圈。搬移期間檔案照常可以開啟使用；搬到一半斷電也不會損壞檔案，因為搬移是由 NTFS 自己完成的。
4. 如果外圈已經被冷資料占住，程式會先讀一次 MFT 找出外圈裡有哪些檔案，挑出能空出**一整塊連續空間**、而且要搬的冷資料最少的那一段，把那裡的冷資料移到內圈（只搬需要的量）。這樣熱資料搬進來時是**一整塊**，不會被拆成很多小段（拆太碎反而會變慢）。
5. **系統還原點**：如果這顆硬碟開了「系統保護」（陰影複製），搬移磁區會讓 Windows 把舊資料複製進還原點的空間，空間不夠時會刪掉較舊的還原點。程式第一次會先停下來問你，按「我了解，繼續」才會開始（你的檔案本身不受影響）。

**外圈／內圈測速**：「熱處理」頁面每顆硬碟的磁區圖旁邊有「📈 外圈／內圈測速」，會從硬碟最前面到最後面讀 10 個位置（只讀不寫，約 20 秒），用長條圖顯示你這顆硬碟外圈到底比內圈快多少——也就是熱處理能幫你省下的時間。

**「熱處理」頁面可以看到和設定的項目**

* 熱資料位在外圈的百分比、還要搬多少、速度、預估剩餘時間。
* **外圈熱區大小**：預設是「熱資料 × 1.15 + 10 GB」。以你的情況，500 GB 熱資料大約需要 600 GB。
* **硬碟使用率上限**：預設 60%。60% 的意思是每搬 0.6 秒就休息 0.4 秒；設成 100% 就是全速。以一般硬碟原地搬移約 60 MB/s 估算，400 GB 在 60% 下約 3 小時，比你要求的 12 小時寬裕很多。
* **時機**：可選一直搬、只在硬碟閒置時搬，或只在指定時段（例如凌晨 1～8 點）搬。
* **讓路**：其他程式讀寫這顆硬碟超過設定的 MB/s 時，熱區搬移會自動暫停。傳輸佇列在用同一顆硬碟時，也會先暫停搬移。
* **試跑**：只計算要搬多少、需要多久，**不會動到任何資料**。建議第一次先開試跑看看結果。
* **磁區圖**：可以看到整顆硬碟哪裡是熱資料、哪裡是空的，以及外圈熱區的範圍。
* 對任一檔案按「內容」或預覽窗格的「📍 查看在硬碟上的位置」，可以看到它有幾 % 在外圈、分成幾段。

**注意事項**

* 熱處理只支援 **NTFS 格式的傳統硬碟（HDD）**。SSD 沒有內外圈的差別，搬了也沒有效果。
* 如果硬碟是 **SMR（疊瓦式）**，例如 WD Blue 6TB（WD60EZAZ），程式會標示「⚠ 可能是 SMR」。這類硬碟內部有位址轉換層，「磁碟區前面＝外圈」不一定成立，大量搬移也會比較慢。
* **請關閉 Windows 對這顆硬碟的自動「最佳化磁碟機」**，否則 Windows 的排程重組可能會把已經排好的位置打亂。步驟：開始 → 輸入「重組」→「重組並最佳化磁碟機」→「變更設定」→「選擇」→ 取消勾選這顆硬碟。
* 重要資料請一律保有備份。這是第一版，我這邊無法在實體 Windows 硬碟上測試磁區搬移，所以**建議先用一個小資料夾試，並且先開「試跑」**。

## 3. 檔案總管

* **分頁**：Ctrl+T 開新分頁、Ctrl+W 關閉、Ctrl+Tab 切換。
* **雙窗格**：Tab 切換左右窗格，**F5 複製到另一邊，F6 移動到另一邊**。
* **網址列**：點一下就能直接輸入路徑（Ctrl+L）。右側的篩選框只篩選目前資料夾；按 Enter 則改為搜尋所有子資料夾。
* **快捷鍵**和 Windows 檔案總管相同：Enter、Backspace、Alt+←／→、F2、Del、Shift+Del、Ctrl+A／C／X／V、Ctrl+Shift+N（新增資料夾）、Alt+Enter（內容），也可以直接打字跳到檔名。
* **左邊的資料夾樹**：點 ▸ 可以展開；開啟資料夾時，樹會自動展開到那一層。
* **拖放**：可以從 Windows 檔案總管拖進來，也可以拖到 Windows 檔案總管或其他程式。規則和 Windows 一樣：同一個磁碟是移動、不同磁碟是複製；按住 Ctrl 強制複製，按住 Shift 強制移動。
* **Windows 剪貼簿互通**：在 Windows 檔案總管按 Ctrl+C，可以在這裡按 Ctrl+V 貼上；反過來也可以。
* **其他**：預覽窗格（圖片、影片、音訊、文字、PDF）、大圖示檢視、資料夾大小（來自索引，不需要等待）、我的最愛。
* 所有複製和移動都會進入**傳輸佇列**，所以多個工作不會互相搶同一顆硬碟。
* 大圖示模式下，資料夾會顯示裡面的照片當**封面**（有 cover／folder.jpg 就用它，沒有就用第一張），找照片資料夾一眼就認得出來。

## 4. 搜尋（Everything 式）

* NTFS 磁碟由背景引擎直接讀取 MFT 建立整顆硬碟的索引，大約幾秒到一分鐘，之後透過 USN 變更日誌**即時更新**。其他格式的磁碟則每 30 分鐘重新掃描一次。
* 搜尋框會記住最近用過的 25 個搜尋，點一下輸入框就能從清單選。
* 支援的語法：

  | 用途 | 寫法 |
  |---|---|
  | 同時包含／任一個／不包含 | `報告 2026`、`a\|b`、`!草稿` |
  | 萬用字元／正規表達式 | `*.mp4`、`regex:` |
  | 副檔名 | `ext:mp4;mkv` |
  | 大小 | `size:>1gb`、`size:100mb..2gb` |
  | 修改日期 | `dm:today`、`dm:thisweek`、`dm:last7days`、`dm:2026-10` |
  | 重複 | `dupe:`（同名檔案）、`sizedupe:`（一樣大小），例如 `dupe: ext:jpg` |
  | 只找資料夾／檔案／空資料夾 | `folder:`、`file:`、`empty:` |
  | 檔案類型 | `video:`、`audio:`、`pic:`、`doc:`、`zip:` |
  | 只找熱資料夾裡的檔案 | `hot:` |
  | 比對完整路徑 | `path:`，或在詞裡加上 `\`，例如 `K:\Work\ 報告` |

  搜尋頁右上角的「？」有完整說明。

## 5. 空間分析（TreeSize 式）

* 左邊是資料夾大小的樹狀表，會顯示每一層佔上一層的百分比；右邊是**方塊圖**，點一下就進入那個資料夾；下方可以切換「最大的檔案」「最大的資料夾」「依類型」。
* 有索引的磁碟會立即顯示；沒有索引的位置（例如網路磁碟）會先在背景掃描。
* 下方的「**依修改時間**」分頁會列出多久沒修改的檔案各佔多少空間（7 天內……5 年以上，以及每一年）。很久沒動的大檔案就是熱處理會移到內圈的「冷資料」。
* 上面的「**⬇ CSV**」會把目前展開的資料夾大小存成 CSV 報表（Excel 可以直接開）。

## 6. 傳輸佇列（Copy Handler／FastCopy 式）

* **通道＝實體硬碟**：例如 K: 和 L: 如果在同一顆硬碟上，就共用同一條通道。每顆 HDD 預設**一次只處理一筆**工作，SSD 預設可同時處理兩筆，數量都可以調整。
* **磁碟最高使用率**：例如設成 80%。程式會以「直接寫入磁碟」的方式寫檔，所以這個比例能準確控制，不會先把資料塞進記憶體、再一口氣灌進硬碟。另外也可以設 MB/s 上限，每顆硬碟都能個別設定。
* **工作管理**：可以暫停、繼續、取消、插隊（⤒）、調整前後順序。程式重新開啟或熱更新後，工作會**從中斷的地方續傳**（未完成的檔案會暫存為 `檔名.hzpart`）。
* **同名檔案**：可選擇問我、略過、覆蓋、較新才覆蓋、比較大才覆蓋、保留兩者。選「問我」時，只有那一個工作會停下來等你決定，其他工作照常進行。
* 可選擇複製後**校驗**（繞過 Windows 快取重新讀取比對），並保留檔案的建立、修改時間與屬性。
* **白天限速**（設定 → 傳輸佇列）：例如 9 點到 23 點之間使用率最多 40%、最多 30 MB/s，晚上自動恢復全速。限速中佇列頁上方會顯示 🌞。
* **完成後**：佇列全部做完可以自動睡眠、休眠或關機（只做一次，關機前有 2 分鐘可以取消）。

### 資料夾同步（FastCopy「同步」式）

在「傳輸 → 資料夾同步」選左右兩個資料夾按「比較」，會列出：只在左邊、只在右邊、左邊比較新、右邊比較新、時間一樣但大小不同、相同（可以勾「連內容一起比對」做逐位元組檢查）。

* **左 → 右 更新**：把左邊多的、比較新的檔案複製到右邊（常用來做備份）。
* **右 → 左 更新**：反過來。
* **雙向**：兩邊互補，比較新的那份贏；「時間一樣但大小不同」的不會動，留給你決定。
* **鏡像 左 → 右**：讓右邊和左邊一模一樣，右邊多出來的檔案放進右邊硬碟的**保管區**（不是刪除）。
* 所有複製都走傳輸佇列（一樣有速度、使用率限制和續傳）；被取代的舊檔一律先進保管區。

## 7. 保管區：檔案不會因為程式出錯而不見

* **原則**：只要是會讓資料消失的動作，程式都會先把原本的檔案**移到同一顆硬碟的隱藏資料夾 `.HotZoneVault`**。同一顆硬碟內只是改位置，瞬間完成、不佔額外空間。包括：
  * 複製或移動時覆蓋同名檔
  * 移動時取代原檔
  * 跨磁碟移動後的原檔（一律保管；如果移動期間資料夾裡多了沒複製到的新檔案，那些新檔案會留在原地，不會被放進保管區）
  * 上傳時選「覆蓋」的舊檔
  * 按 Del 刪除
* 每一筆都記錄原本的位置、時間和**原因**，例如「複製時被覆蓋：新的檔案來自 D:\a.jpg」。
* 保管區頁面可以依原因篩選（刪除、被覆蓋、移動後的原檔、上傳時被覆蓋、轉 MP4 後的原檔……），也可以搜尋原本的位置；圖片和影片會顯示縮圖，點一下看大圖。
* 保管 30 天（天數可以設定）之後，會移到「**待你決定**」，由你在「保管區」頁面決定要還原、繼續保留，還是永久刪除。
* **還原**會放回原本的位置；如果那裡已經有檔案，會取名為「名稱 (還原)」，不會蓋掉任何東西。
* **永久刪除（Shift+Del）**要在畫面**三個不同位置**各確認一次，刪了就不留檔。伺服器端也會檢查，就算從手機操作也一樣要確認三次。
  * 要刪的清單在你確認的那一刻就定下來：之後才放進那個資料夾的檔案、確認後被修改過的檔案，都不會被刪。
  * 資料夾裡如果有「連結資料夾」（junction／符號連結），只會刪掉連結本身，不會刪到它指向的地方。
* **重新命名**遇到同名一律拒絕，不會覆蓋。**批次改名**會先把計畫寫到硬碟上，中途失敗會全部改回原名；就算當下停電，下次啟動也會自動改回。
* **永久刪除的檔案在你確認之後被修改過**（例如被別的程式存檔），程式會拒絕刪除，請你重新確認。
* 保管區每次啟動都會自我檢查，如果資料庫漏記了某個項目，會從保管區裡的 .json 紀錄補回來。
* **操作紀錄**：所有動作都記錄在「紀錄 → 操作紀錄」，可以搜尋，也能展開看詳細內容。
* **復原（Ctrl+Z）**：重新命名、新增、移動、複製、批次重新命名、刪除（從保管區放回原處），都可以復原。

## 8. 生圖比較（ComfyUI／A1111）

1. 在「圖片 → 生圖比較」輸入 ComfyUI 的 output 資料夾，按「讀取」。程式會讀出每張 PNG 裡的生成參數。
2. 程式會**自動找出這批圖之間有哪些設定不一樣**，包括：
   * Seed、CFG、Steps、取樣器、模型、LoRA 和權重
   * 提示詞裡被換掉的詞（「提示詞差異」）
   * 每一個節點的參數（進階）
3. 選擇 **X 軸、Y 軸**就會排成表格；第三個會變的參數可以設成「**分頁軸**」，用 PageUp／PageDown 翻頁。200×200 的表格也很順。
4. 可以調整的項目：
   * 格子大小（也可以 Ctrl+滾輪縮放）
   * **間距**：可以拉成負的，讓圖片重疊堆在一起
   * **邊緣漸層**：相鄰的圖會融在一起
   * 圓角、格線和格線顏色、背景色
   * 填滿格子或完整顯示
   * 標籤開關、排序方向、X／Y 對調
5. 點欄或列的標題，可以只看那一欄或那一列；在標題上按右鍵可以隱藏它；「篩選」可以挑要看哪些參數值。
6. 點任何一格會放大。可以用方向鍵在表格裡移動，提示詞裡**跟其他圖不同的詞會反白**，也能一鍵複製提示詞或 seed，或「**複製工作流**」（貼到 ComfyUI 就能載入同一個工作流）。
   * **A/B 比較**：在一張圖按 A 設成比較基準，切到另一張再按 C，畫面會左右分割，拖曳黃色分隔線比較兩張的差別。
   * 在欄／列標題按右鍵：只看這一欄、隱藏、**往前／往後移、移到最前面或最後面**（自訂順序會記住）、複製這個值。
   * 同一格有多張圖時，可以選「**拼成小格**」，把它們全部縮小排在同一格裡。
   * 「**格內文字**」可以在每一格下方顯示某個參數（例如 seed 或檔名）。
7. **挑選**：游標移到圖上按 P，或點右上角的 ☆。之後可以「只看挑選的」，或「把挑選的複製到…」其他資料夾。欄／列標題旁的 ★數字 是那一欄挑了幾張；「⬇ 下載挑選的」打包成 zip；挑了 3 張以上會出現「📊 挑選分析」：每個參數的每個值被你挑了幾成，差距最大的參數排最上面，用來找出真正影響你喜好的設定。
8. **匯出成一張圖**：會照目前的間距、漸層和標籤，輸出一張大 PNG。
9. 每個資料夾的版面設定都會自動記住。
10. **同步放大鏡**：滑鼠停在任何一格上**按住 Z**，畫面上每一格都會放大到同一個位置（用原圖，不是縮圖），最適合比較手指、眼睛、衣服細節在不同 seed／CFG 下的差別。按住 Z 時用滾輪調倍率（1.5～12 倍），放開就恢復。
11. **即時跟隨**：ComfyUI 還在出圖時打勾，新圖一產生就會自動加進表格，新的那幾格會閃黃框 20 秒，版面和捲動位置都不變。

## 9. 圖片分類（不用 AI，純程式判斷）

在「圖片 → 圖片分類」裡，先加入你的圖片資料夾。程式會在背景把每張圖分析一次，20 萬張大約要一個晚上；改過的圖片才會重新分析。傳輸佇列在工作時，分析會自動暫停。左邊可以用下面這些條件挑圖，而且可以同時用好幾個：

* **顏色**：紅、橙、黃、綠、青、藍、紫、粉、棕、黑、白、灰，判斷的是「你一眼注意到的那個顏色」。每張縮圖下方的色條是它的主要顏色。
* **人臉**：沒有人、1 個人、多人。使用傳統的 OpenCV 臉部偵測，沒有用神經網路，只分辨「有沒有人、幾個人」，不分辨是誰。
* **形狀與畫質**：直式、橫式、方形，螢幕截圖，可能模糊、清晰，偏暗、偏亮，有 GPS 位置，800 萬像素以上。
* **拍攝資訊**：年份、月份、相機或手機型號，來自 EXIF。
* **⭐ 最愛**：看大圖時按 **F**（或按「加入最愛」、右鍵選單），左邊「其他」裡的「⭐ 最愛」可以只看最愛。最愛另外記錄，重新分析也不會不見（在這個程式裡改名或移動，最愛會跟著走）。
* **時間軸**：依拍攝時間排序時，畫面會依月份分段（2024 年 12 月 · 236 張……），像手機相簿一樣往下捲。
* **對這些圖片…**：把目前篩選出來的所有圖片一次複製、移動、放進保管區，或複製全部路徑（最多 5 萬張）。
* **依拍攝日期整理**：在「對這些圖片…」選「依拍攝日期整理」，照片會依 EXIF 拍攝日期分到 `2024\12` 這樣的年／月資料夾（格式可選）。可以選移動（同一顆硬碟瞬間完成，可 Ctrl+Z 復原）或複製；同名時自動另取名字，不會覆蓋。
* **相近套圖**：同一個資料夾裡、拍攝時間接近、畫面又相似的連拍會自動歸成一組，可以整組移動。
* **找相似的**：在圖上按右鍵 →「找相似的圖片」，程式會用畫面結構和顏色比對。
* **近似重複**：同一張圖存了好幾份（縮小過、重新壓縮、轉成別的格式）會歸成一組。★ 是建議保留的那張（像素最多、最清晰、檔案最大），其他的預設打勾；點縮圖可以改勾選，雙擊放大看。按「放進保管區」只是移進保管區，保管期限內都能還原，而且每張都記著「保留的是哪一張」。判斷的嚴格程度可以調。

* **文字找圖（不用 AI）**：在上方的搜尋框輸入「聖誕節」「海邊」「和服」「紅色」「貓」…
  * 會比對**資料夾名稱、檔名**，以及**圖片裡存的文字**：ComfyUI／SD 的提示詞、Windows 的標籤／主旨／註解、Lightroom 等軟體寫入的 XMP 關鍵字。
  * 內建中、英、日**同義詞表**：輸入「聖誕節」也會找 christmas、xmas、santa、聖誕樹、麋鹿、クリスマス…；輸入「西裝」會找 suit、tuxedo。
  * **節日會比對拍攝日期**：聖誕節 = 12/20～12/26 拍的照片，春節 = 每年農曆新年前後，另外還有新年、萬聖節、情人節。
  * **顏色字**（紅色、blue…）會比對主色。
  * 空白分開＝「而且」，前面加 - ＝排除，例如「聖誕節 -和服」。每張圖都會顯示**為什麼符合**（例如「christmas 在提示詞裡」或「拍攝日期 2024/12/25 在聖誕節期間」）。
  * 限制：如果圖片沒有任何文字（相機直接拍的照片、資料夾也沒取名），就只能靠拍攝日期和顏色；要真正「看懂畫面內容」需要下面的離線模型。

> 進階功能需要「本機離線模型」，要等你同意才會做：人臉分成不同的人，以及看懂畫面內容的文字找圖（沒有任何文字的照片也找得到）。

### 影片工具

「圖片與影片 → 影片工具」選一個資料夾（可含子資料夾），會列出每支影片的**長度、解析度、FPS、編碼、大小**和總長度，可以依長度或解析度排序。

* **無損轉成 MP4**：FLV、TS、MKV 等錄影檔可以直接轉成 MP4，**不重新壓縮**（畫質完全一樣，一支幾分鐘就好）。也可以在檔案總管對影片按右鍵 →「無損轉成 MP4」。
  * 新的 MP4 先用暫存檔名寫好，檢查有影像、長度和原檔一致，才改成正式檔名；同名的 MP4 已經存在時會另外取名，不會覆蓋。
  * 原檔可以選擇保留，或放進保管區（保管期限內可還原）。轉失敗時原檔完全不動。
  * 傳輸佇列在工作時會先等它做完，不會搶硬碟。
* 影片如果有**字幕或附件軌**（MKV 常見），文字字幕會轉成 MP4 字幕，但原檔一律保留不動，避免 MP4 放不下的軌道消失。
* 需要 **ffmpeg.exe**（最好連 ffprobe.exe）放在程式資料夾；如果旁邊有 TikLive Monitor 的資料夾，程式也會自動找它的 ffmpeg。

## 10. 其他工具

* **重複檔案**：比對的順序是先比大小（來自索引，很快），再比檔案的開頭和結尾，最後完整比對。可以一鍵勾選要刪的，例如保留最舊的、最新的、路徑最短的，或熱資料夾裡的那份。刪除的檔案會放進保管區。
* **批次重新命名**：選多個檔案後按 F2。支援：
  * 尋找取代（可以用正規表達式）
  * 用 `{name}` `{n:3}` `{date}` `{time}` `{taken}` `{ext}` 組合新檔名。`{taken}` 是照片的拍攝日期時間（EXIF），例如 `{taken}_{n:3}` 會變成 `20241225_203015_001.jpg`
  * 生圖的 PNG 還可以用 `{seed}` `{cfg}` `{steps}` `{sampler}` `{model}`（從圖裡存的生成參數讀出來），例如 `{model}_cfg{cfg}_{seed}`
  * 可以勾「先依拍攝時間排序再編號」：不同相機、手機的照片合在一起時，編號會照真正拍攝的順序
  * 前後加字、改大小寫、改副檔名
  * 下方會即時預覽改名結果
* **縮圖**：檔案總管的「大圖示」會顯示圖片和影片的縮圖。影片縮圖需要 ffmpeg.exe，放在程式資料夾或系統 PATH 裡都可以。
* **手機 QR code**：設定頁的網址旁邊按「📱 QR」，用手機掃描就能連線。
* **手機操作**：在手機上**長按**檔案就會出現右鍵選單。

## 11. 遠端（區網／Tailscale）

1. 在電腦端的 **設定 → 遠端連線**，勾選「允許遠端連線」，並**設定網頁密碼**（沒有設密碼時，遠端裝置無法登入）。
2. 手機和電腦都安裝 Tailscale，並登入同一個帳號。
3. 用手機瀏覽器開啟設定頁上顯示的 Tailscale 網址，畫面和電腦上相同，所有功能都能用，還多了上傳和下載。
4. 如果想把網頁裝成手機 App：在設定頁按「開啟 Tailscale HTTPS」，然後用 Chrome 選「安裝應用程式」，或用 Safari 選「加入主畫面」。
5. 安全設計：遠端裝置不能讀取程式自己的資料夾（金鑰、密碼雜湊）、不能上傳更新包、不能改連線設定；從硬碟開啟的網頁檔不會被執行；密碼錯 5 次後該裝置要等 1 分鐘、之後逐步加長。只接受用 IP、電腦名稱、`*.ts.net` 連線；如果你用自己的網域，請在 `Data\settings.json` 的 `web.hosts` 加入它。

## 12. 熱更新

* 更新包的格式和 TikLive Monitor 相同：

  ```
  v0.1.1_Update.zip
  ├─ manifest.json        {"version": "0.1.1", "requires_launcher": 1}
  └─ app\...              有變更的檔案和 CHANGELOG.json
  ```
* 三種安裝方式：
  * 拖進「更新」頁，或按「選擇更新包」
  * 放進 `UPDATE\` 資料夾，程式會提示你；下次開啟程式時也會自動套用（遠端網頁也可以按「套用」這種更新包）
  * 為了安全，**上傳新的更新包只能在這台電腦上做**（更新包裡是程式碼，會以系統管理員權限執行）
* 更新時，**搬檔、熱區搬移、索引和遠端連線都不會中斷**：舊版會在安全的時間點停下來，把狀態交給新版接手。新版如果載入失敗，程式會**自動還原**成原本的版本。
* 每次更新前都會自動備份到 `app_backup\`，在「更新」頁可以一鍵退回任一個舊版本。
* `tools\make_update.py` 可以把 `app\` 打包成更新包。之後請 Claude 改程式時，把整個 `app\` 或最新的更新包給它即可。

## 13. 資料夾結構

```
HotZoneFM.exe, _internal\   啟動器（build_exe.bat 產生，很少需要重做）
launcher.py                 啟動器的原始碼
app\                        程式本體（熱更新會替換這裡）
UPDATE\                     放更新包的地方
app_backup\                 每次更新前的自動備份
Data\                       設定、佇列、熱資料夾、搜尋索引快取、操作紀錄（safety.sqlite3）、縮圖
X:\.HotZoneVault\           每顆硬碟的保管區（隱藏；請不要手動刪除）
LOG\                        紀錄檔：engine.log、startup_log.txt、update_log.txt
```

## 設定備份

「設定 → 💾 設定備份」可以把所有設定（熱資料夾、我的最愛、佇列、熱處理、圖片分類……，不含密碼）匯出成一個檔案，重灌或換電腦後再匯入。匯入時不會帶入只屬於那一次或那一台電腦的設定（「佇列做完後關機」、系統還原點的同意），每個值都會先檢查；匯入前目前的設定會另存成 `Data\settings.before_import_時間.json`。

## 打包下載（zip）

在檔案總管或生圖比較選好檔案後按「下載」，會打包成一個 zip（手機也可以）。同名檔案會自動加 (2)；連結資料夾（junction）不會跟進去；如果有檔案讀不到或讀不完整，zip 裡會多一個 `HotZone_未包含的檔案.txt` 列出來——**刪除原始檔之前，請先確認 zip 裡沒有這個檔案**。

## 14. 疑難排解

* **有問題要回報**：先到「設定 → 背景引擎」按「🩺 自我檢查」，再按「📦 匯出診斷資料」，把下載的 zip 傳給我。裡面只有紀錄檔、設定（不含密碼）和各功能的狀態，沒有你的檔案內容。
* **背景引擎沒有回應**：查看 `LOG\startup_log.txt` 和 `LOG\engine.log`，或在程式的「紀錄」頁查看。
* **有開代理伺服器（Clash、v2rayN）**：程式和背景引擎之間的連線已經設定成不經過代理，不需要另外設定。
* **筆電用電池時背景沒有啟動**：到「設定 → 背景引擎」把「開機自動啟動」關掉再打開一次（舊版建立的排程有「只在插電時執行」的預設值；新版啟動時也會自動更新它）。
* **熱區顯示「無法使用」**：可能的原因有三個：背景引擎不是以系統管理員身分執行、磁碟不是 NTFS，或磁碟是 SSD。
* **連接埠 8765 被占用**：到「設定 → 遠端連線」改成其他連接埠。
* **沒有 PySide6 視窗**：雙擊 `open_in_browser.bat`，改用 Edge 或 Chrome 開啟同一個介面。
* **第一次開 exe 出現「Windows 已保護您的電腦」**：這是因為自己製作的 exe 沒有數位簽章。按「其他資訊」→「仍要執行」即可，只有第一次會問。
* **防毒軟體把 exe 或 `_internal\` 誤判**：PyInstaller 做出來的程式偶爾會被誤判。可以把整個 HotZoneFM 資料夾加到防毒的「排除項目」，或改用 `run_from_source.bat` 直接以 Python 執行（功能完全一樣）。
* **斷電或當機之後**：不用做任何事。啟動時會自動整理保管區的紀錄、接著做未完成的佇列工作；佇列裡被中斷的檔案會從斷點繼續，已經複製好的檔案會逐位元組比對確認，不會重複或覆蓋。如果某個工作的清單在斷電時損壞，它會顯示錯誤（不會假裝完成），檔案都還在原處，重新加入即可。
